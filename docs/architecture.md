# ארכיטקטורה

## רכיבים מרכזיים

- **Daemon (`shabatosd`)**: אחראי על תזמון כניסה/יציאה ממצב שבת.
- **Lockdown**: שכבת חסימה שמיישמת Firewall, חסימת אפליקציות והשתקת התראות.
- **CLI (`shabatosctl`)**: ממשק ניהול למשתמש ולמפעיל מערכת.
- **Config**: קובץ YAML שמגדיר מדיניות.

## גבולות מערכת

- לא מבצע ניטור תוכן אישי או איסוף מידע.
- לא מבטל הרשאות מערכת קיימות, אלא מוסיף שכבות הגנה.
- מכבד מצב חירום מוגבל בזמן ובהרשאות.

## תלויות

- systemd לניהול שירותים וטיימרים.
- nftables או UFW לחסימת רשת (לפי הגדרות).
- Python 3 להרצת daemon וה־CLI.
