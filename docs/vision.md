# חזון ShabatOS

ShabatOS נועדה להעניק למשתמשים חוויית מחשוב שמכבדת את קדושת השבת באמצעות מצב
"שבת" חכם, שקט, ומוגבל. החזון כולל:

- מעבר אוטומטי וידידותי למצב שבת לפי לוחות זמני כניסת ויציאת שבת.
- שמירה על פשטות ויציבות מערכתית — מינימום הפתעות במהלך השבת.
- מסלול חירום (Pikuach Nefesh) מוגדר מראש ובטוח.
- הקפדה על שקיפות: מה נחסם, למה, ואיך ניתן להכין מראש.
