# Security Policy

## Supported Versions

We currently support the latest `main` branch only. Please upgrade to the most
recent commit before reporting a security issue.

## Reporting a Vulnerability

If you discover a security issue, please report it privately by emailing
`security@shabatos.org` (placeholder address) with:

- A clear description of the issue.
- Steps to reproduce (proof-of-concept, if possible).
- Potential impact and any suggested mitigations.

We will acknowledge receipt within 72 hours and provide a timeline for
remediation once triaged.

## Coordinated Disclosure

Please do not disclose security issues publicly until we have released a fix
and coordinated a disclosure timeline with you.
